# Tutor Platform Functions

## Onboarding
- User registration and profile setup
- Tutor approval workflow (admin must approve before tutors can teach)
- Distributor referral codes and parent-distributor linking
- Distributor onboarding
- Teacher class code generation for student enrollment
- Welcome/onboarding emails

## Student Tests
- Test mode vs learning mode
- Question attempt tracking
- Classroom-wide assessments (teacher-initiated)
- Parent email

## Skills
- Skill hierarchy and tree structure
- Skill matrix visualization
- Knowledge base — formulas, rules, definitions attached to skills
- Multiple template upload

## Learning
- Focus area progress tracking (pre/post competency snapshots)
- Competency levels (0–5 scale)
- Calculator

## Reporting on Progress
- Student progress reporting
- Weekly competency snapshots
- Session-end competency snapshots
- Teacher gap analysis — class-wide skill weaknesses
- Class focus area tracking

## Finding Tutors
- Parent search for tutors
- Tutor profiles, bios, and qualifications
- Tutor availability display
- Distributor referral program connecting parents to the platform

## Bookings
- Bookings between students and tutors
- Tutor weekly availability and blocked days management
- SMS notifications for booking confirmations and changes

## Online Tuition Sessions
- SMS follow-up messages to students
- Video conferencing via LiveKit (WebRTC)
- Real-time collaborative whiteboard
- Calculator
- Test mode and focus area/learning mode within sessions

## Post Session Reviews
- Parent ratings and comments
- Tutor post-session review job
- Tutor message to parents
- Focus area review

## Payments
- Stripe payment processing
- Multi-party settlement (platform, tutor, distributor, parent)
- Payment status tracking (pending → authorised → paid → confirmed)
- Tutor billing dashboard and fee setting
- Bank account management for tutors
- Distributor commission tracking
- Admin payment management and authorization
- SMS and email notifications for payment failures, overdue alerts, and receipts

## Template Editor
- Template creation, editing, and duplication
- Difficulty variations (easy/medium/hard trios)
- Template flagging and validation
- Import/export
- Diagram creation and editing
- Knowledge base editor (reusable concepts attached to skills)
- Template translations (Chinese, Arabic, Vietnamese, Korean, Hindi, Spanish, French, Italian, Portuguese)

## Jobs
- Admin job queue (approve tutors/distributors, payment issues, low session ratings, bank detail setup, overdue reviews)
- Tutor job queue (post-session review, progress messages, fee setup, payment issues)
- Parent job queue (payment due/failed/overdue notifications, session pause alerts)
- Email and SMS triggered by job events

## Teacher & Classroom
- Teacher registration and profiles
- Class creation and student management
- Classroom-wide assessments
- Class focus areas
- Gap analysis and reporting
- Teacher communications to class

## Distributor & Referral Program
- Distributor registration and onboarding
- Referral code generation
- Parent-distributor linking
- Distributor commission tracking within payments

## Admin Management
- Global platform settings (dynamic configuration)
- User management across all roles
- Bulk email and SMS broadcasts to users
- Parent feedback and complaint system with admin responses
- Admin inbox for platform communications

## Marketing & Public Pages
- Public landing pages
- Tutor and teacher recruitment pages
- Distributor marketing pages
- Platform principles and philosophy pages
